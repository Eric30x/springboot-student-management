# Student Management System

基于 **Spring Boot + MySQL** 开发的学生管理系统，用于练习 Java Web 后端开发及 RESTful API 设计。

## 技术栈

- Java
- Spring Boot
- MySQL
- Maven
- Spring Data JPA

## 项目功能

- 学生信息查询
- 添加学生
- 修改学生信息
- 删除学生
- RESTful API 接口
- 数据库持久化

## 项目结构

- `controller`：接收和处理 HTTP 请求
- `service`：业务逻辑处理
- `repository`：数据库访问
- `entity`：实体类

## 运行方式

1. 安装 JDK、MySQL 和 Maven。
2. 创建项目所需的 MySQL 数据库。
3. 配置 `application.properties` 中的数据库连接信息（不要提交真实密码）。
4. 运行 Spring Boot 启动类。

## 项目说明

本项目是 Java 后端学习过程中的实践项目，主要用于巩固 Spring Boot、MySQL、分层架构及 RESTful API 开发知识。
